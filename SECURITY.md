# Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Kutlu24/swipeskip/security/advisories/new) on the repository, or by email to wintechpartners@gmail.com. Please do not open a public issue for security problems.

Scope notes: the app has no server, no account and, in the `foss` flavor, no network permission. The most sensitive component is the accessibility service; it is restricted to the YouTube package and never stores screen text.
