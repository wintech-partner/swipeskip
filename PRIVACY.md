# Privacy policy (template)

Host this text where the store listing can link to it.

**SwipeSkip does not collect, store or transmit personal data.**

- No account, login, analytics, crash reporting or advertising.
- Settings (interval, limits, theme, language, consent flag) are stored only in the app's local storage on your device.
- The accessibility service, while a session you started is running, looks at the *structure* of the YouTube screen (view names, positions, labels used to recognise things like an ad badge) in memory only. It never stores or sends titles, comments, usernames or any other on-screen text.
- If you enable motion-to-next, the accelerometer is read during a live session only to detect a flick; the readings are never stored or sent.
- If you enable "Tap Skip automatically" (not available in the Play build), the app taps YouTube's own Skip button when it is likely visible.
- Diagnostics reports are created only when you tap "Copy report" and contain no screen content. Nothing is uploaded by the app.
- The open-source (`foss`) build has no internet permission. The Play build adds the permissions required by Google Play Billing, used only for the optional premium purchase.

Contact: wintechpartners@gmail.com, or open an issue at https://github.com/wintech-partner/swipeskip/issues, or, for anything sensitive, use a private [security advisory](https://github.com/wintech-partner/swipeskip/security/advisories/new).

## Browser extension
The SwipeSkip browser extension runs only on www.youtube.com, stores its settings locally in the browser (`storage`), reads no page text, makes no network requests and collects no data.
